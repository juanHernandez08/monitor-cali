# Fotos de candidatos (opcional)

Para que el Resumen y la pestaña Candidatos muestren una foto real en vez de las
iniciales, coloca aquí un archivo `<candidate_id>.jpg` (o `.jpeg`/`.png`/`.webp`)
por candidato. El id es el mismo que usa `/api/social/candidates`.

No se usa la foto de perfil que trae el scraper de Instagram porque esa URL viene
firmada y caduca en horas (Instagram devuelve 403 poco después) -- verificado
2026-09-30. Una foto puesta aquí a mano es la única forma confiable y gratuita de
mostrar una imagen real.
